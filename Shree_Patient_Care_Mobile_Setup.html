Firebase Setup Helper

यह मोबाइल-फ्रेंडली सेटअप पेज है। साझा और सुरक्षित मरीज रिकॉर्ड के लिए इसे HTTPS वेबसाइट पर होस्ट करना और Firebase सेटअप पूरा करना जरूरी है।

महत्वपूर्ण: अभी इसमें मरीजों का वास्तविक डेटा दर्ज न करें। यह Firebase से कनेक्ट नहीं है और इसमें लॉगिन/डेटाबेस चालू नहीं है।

Firebase Web Configuration

Firebase Console → Project settings → Your apps → Web app → Config में ये मान मिलेंगे। यहाँ पासवर्ड नहीं भरना है।

अगले चरण

  1. Firebase Authentication में Email/Password enabled रखें।
  2. Admin role के लिए users/{UID} document में role: "admin" और active: true होना चाहिए।
  3. ऐप को HTTPS पर deploy करें; केवल HTML file खोलना साझा cloud app के लिए पर्याप्त नहीं है।
  4. Security rules और roles की जाँच के बाद ही वास्तविक मरीजों का डेटा इस्तेमाल करें।

Firebase config में apiKey होना सामान्य है, लेकिन वह सुरक्षा का विकल्प नहीं है। सुरक्षा Authentication और Firestore Rules पर निर्भर है। Firebase password या service-account private key साझा न करें।
